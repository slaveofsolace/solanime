# Deployment guide moved

Use [CLOUD_RELEASE.md](CLOUD_RELEASE.md) for the integrated Workers/D1 release and
the repository [README](../README.md) for Windows/macOS local setup. Binary patch

patch over this integration or overwrite a newer catalogue/private account store.
