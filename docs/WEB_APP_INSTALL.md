# Install Solanime as a web app

Open [solanime.pages.dev](https://solanime.pages.dev/) over HTTPS and sign in with your approved account. The installed web app is the same hosted site and needs an internet connection for catalogue and video playback.

## Mac

In Safari on macOS Sonoma 14 or newer, open Solanime, then choose **File → Add to Dock** (or **Share → Add to Dock**). Name it Solanime and select **Add**. Open it from the Dock or Applications folder. Safari web apps keep their own website data, so you may need to sign in again.

In Chrome, open Solanime and use the browser's **Install** button in the address bar or menu when offered. The install option may appear after you have interacted with the site.

## iPhone

Open Solanime in **Safari**. Tap the page menu or Share button, choose **Share**, then **Add to Home Screen**. Enable **Open as Web App** if shown, then tap **Add**. Launch Solanime from its Home Screen icon and sign in if needed.

If **Add to Home Screen** is absent, scroll to **Edit Actions** and add that action. Do not download the Windows desktop ZIP to an iPhone; it cannot install there.

## Playback limitation

Installing the website does **not** turn it into the separate protected desktop or native mobile player. A web app cannot control popups or redirects created inside a cross-origin provider iframe with the app-owned window policies used by those prototypes. Treat provider-hosted playback on Mac Safari and iPhone as unverified until it is tested on those devices. If a provider opens unwanted content, close it and do not continue using that provider in the web app.

The web app intentionally has no offline media cache. Account data, catalogue responses, and playback references must come from the live service.
