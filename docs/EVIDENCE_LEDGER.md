## Evidence-state vocabulary

- `observed`: captured directly from a dated public response or rendered page.
- `corroborated`: supported by independent current source code or multiple sources, but not captured from the target flow.
- `inferred`: plausible relationship that remains unproven.
- `unknown`: evidence is insufficient.
- `blocked`: an explicit access, policy, embedding, availability, or execution condition prevents the check.
